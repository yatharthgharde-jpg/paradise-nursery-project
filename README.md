
# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is an online plant shopping application where users can browse houseplants, view their prices, and add plants to a shopping cart.

## Features

- Browse plants by category
- View plant names, images, and prices
- Add plants to the shopping cart
- Increase or decrease item quantities
- Remove plants from the cart
- Calculate the total price
- Responsive user interface

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- GitHub
